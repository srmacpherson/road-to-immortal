**Road to Immortal** is a Dota 2 progression and analytics platform designed to help players understand their improvement, identify weaknesses, and make more informed decisions about how they play. 
The project is being built alongside my own journey from approximately 5.3k MMR toward Immortal, using my personal match history as the initial real-world dataset. 
Rather than being another website that simply displays Dota 2 statistics, the goal is to transform raw match data into meaningful insights about progression, performance, trends, hero pools, win conditions, 
and areas for improvement. 
Over time, the platform will evolve from basic MMR and match tracking into a personalised improvement tool that can answer questions such as how a player is progressing, what they are doing well, 
where they are losing games, and what they should focus on next.

The application is also intended to be a substantial software engineering project and portfolio piece, combining several technologies and disciplines into a single real-world product. 
The frontend is being built with **React and TypeScript**, providing an interactive dashboard for visualising MMR progression, match history, hero performance, trends, and analytical insights. 
The backend uses **ASP.NET Core and C#**, providing a structured API, business logic, data processing, and integration with external Dota/Steam services. 
**Entity Framework Core** is used as the data-access layer, with **PostgreSQL** providing persistent storage for player profiles, matches, statistics, and eventually derived analytics. 
**Docker** is used to provide a consistent local development environment, while the project will eventually incorporate technologies such as background jobs, caching, automated testing, 
CI/CD, and cloud deployment as the application grows.

The project therefore demonstrates more than familiarity with individual frameworks. It provides practical experience in **full-stack application architecture, REST API development, third-party API integration, 
database design, data modelling, analytics, data visualisation, asynchronous/background processing, testing, containerisation, deployment, and product development**. 
The Dota-specific domain also provides an opportunity to work with a large volume of structured game data and turn it into useful, user-facing information. 
Ultimately, Road to Immortal is both a genuine product and a technical journey: a platform built to analyse the process of reaching Immortal while simultaneously demonstrating the ability to design, 
build, deploy, and evolve a modern full-stack application from the ground up.
